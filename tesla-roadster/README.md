# Tesla Roadster collection report

A static, public report of a saved 40-post TikTok search collected on 16 October 2026. Open `index.html` through a local HTTP server; no build, credentials, tracking or backend required.

`data/posts.csv` preserves public post fields as collected. `data/posts.json` is a normalized export with collection metadata, public post fields, video duration and local preview paths. Internal actor receipts and signed CDN URLs are not included. `data.js` supplies the same data to the UI without an extra request.

Collection: queries `tesla roadster` and `tesla roadster backflip`; past 24 hours; most liked; 20 results per query; clockworks/tiktok-scraper 0.0.619. One snapshot; no growth estimates or unique reach claims.

Images are attributed to their original creators through the adjacent source links. The full collection screenshot is included as requested. This report is not affiliated with Tesla or TikTok.
